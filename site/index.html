Why agents run
on dexter.

Four operating convictions, enforced by the runtime — not by the prompt.

I

Semantic first

accessibility tree · dom · ocr evidence

Elements carry role, name, and actions — not pixels. Coordinates exist, behind a gate, for when semantics genuinely run out.

II

Fail closed

policy outside the llm · fingerprint grants

Unmatched mutations return needs_approval, never a guess. Trust lives with the operator; the agent cannot approve itself.

III

Non-invasive by default

semantic · synthesised · physical floor

Every action reports an intrusiveness tier derived from its target. Physical input is never taken implicitly.

IV

Receipts, not vibes

live audit · replayable · honest counters

Every step lands in a bounded journal: context, decision, result, evidence. Uncertainty is reported, never smoothed over.

One loop,
four verbs.

The agent drives. Dexter runs the cycle — bounded, cancellable, journaled.

01

observe

A semantic digest of the live window tree plus structured element ids. Reads are free.

dexter_observe → observation 14 · 38 elements
02

candidates

A ranked menu of what the world affords right now. Advisory; the agent still decides.

dexter_candidates → c0 click e_7
03

act

Every mutation passes the policy engine. Approvals are fingerprints a human grants.

dexter_act → needs_approval fp:a91c
04

verify

Expected state is checked against a fresh observation. Misses trigger bounded recovery.

dexter_verify → status: pass
verify failed → RecoveryStarted → reobserve bounded: max_attempts · max_secs · dexter_cancel

Nine tools,
one stdio server.

Register once in your harness config. The same engine backs the CLI and the MCP surface.

dexter_observe{app?, window?, vision?, max_elements?}semantic digest + structured elements
dexter_candidates{goal, app?, max?}ranked advisory action menu for a goal
dexter_act{action, app?, expect?}policy-gated step: act, verify, recover
dexter_grant{fingerprint}human approval for a fingerprint
dexter_verify{expected, app?}check expected state against the world
dexter_task{goal, done, app?, max_steps?, max_secs?}optional closed loop to a done condition
dexter_journal{}live audit trail, readable mid-run
dexter_cancel{}cooperative stop for the running task
dexter_status{}driver + engine health, live
