04

verify

Expected state is checked against a fresh observation. Misses trigger bounded recovery, not blind retries.

dexter_verify(expected)
→ status: pass

Policy is outside the model.

Agents propose. Dexter disposes. Trust flags are set by the operator when the server starts; tool calls cannot raise their own privilege.

  • Fail closed. Unmatched mutations return needs_approval, never a guess.
  • Human grants. Fingerprints are single-use and TTL-bound via dexter_grant.
  • Physical floor. Coordinate and keyboard input is denied by default; --coords is an operator flag, and the mutating gate still applies after it.
  • Stale targets rejected. Element references carry their observation id; a changed world invalidates them.
[defaults]
physical = "deny"

[[rule]]
action = "click"
app = "bundle:com.apple.Terminal"
decision = "allow"

[[rule]]
action = "*"
app = "name:System Settings"
decision = "deny"
reason = "never touch system settings"

Non-invasive by default.

Every action reports an intrusiveness tier derived from its target, never from the model.

background

Semantic DOM and accessibility mutations. Your cursor and focus never move; apps do not need to be in front.

visual

Visible but non-capturing: navigation, window focus, scrolling. You see it happen; you keep the wheel.

physical

Real pointer and keyboard. Denied unless the operator opted in, and always rendered red in the presence overlay.
